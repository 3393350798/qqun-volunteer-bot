# Q群志愿机器人

Windows 本地 QQ 志愿活动报名助手。读取指定可见群的活动消息，打开 WPS / 金山文档在线表格，结合不可用时间和 ICS 日历选择报名时段，并提供多表监测、报名记录及周课表界面。

当前主要适配 WPS 画布表格。腾讯文档链接可识别，实际填写能力需要针对页面结构配置和实测。QQ、Edge 和文档账号由使用者在本机登录。

## 功能

- 按 QQ 可见消息气泡提取活动链接；支持指定群名过滤和文档去重。
- 从表格日期、星期、时段及学期周上下文重建活动时间。
- 周历、文本规则、ICS 课程与忙碌时间过滤。
- 按表头定位姓名、学院、学号、联系方式，填写符合条件的行并读回确认。
- 多表独立线程监测空位、打开失败重试、提前截止、异常表格线程重启。
- 日程与已知表格按学号同步；跨表冲突可配置允许，并显示冲突链接。
- 周课表、ICS 导入、日志与记录管理；显示时间默认 08:00–23:00。
- 可选 QQ 二维码识别及入群申请；微信目前支持打开邀请。

## 启动

环境：Windows、Python 3.11 或更新版本、桌面 QQ、Microsoft Edge。Python 需在 PATH 中，也可使用项目内 `.venv`。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_ui.py
```

也可双击根目录的 `go.bat`。启动器优先使用 `.venv`，否则使用 PATH 中的 `python`，缺少主要依赖时尝试安装。

首次启动自动在根目录创建唯一的 `config.yaml`，包含逐项中文注释；个人字段为空，演练模式开启，二维码和自动加群关闭。现有配置会继续保留。所有编辑均写入这份本机配置。

1. 在“个人资料”填写目标测试表需要的信息。
2. 在“QQ 监听”设置目标群名，让该群保持可见。
3. 在“运行设置”填写学期第一周的周一；直接日期场次可独立解析。
4. 在“不可用时间”配置周历、文本规则或导入本机 ICS。
5. 点击打开 Edge 登录会话，完成文档登录。程序使用本机 9222 调试会话；首次登录后通常可以复用该专用浏览器目录。
6. 用自己拥有的复制测试表调整表头行、扫描列和扫描范围，先执行演练。
7. 核对演练结果后关闭演练模式，允许对测试副本实际填写。

命令行启动：

```powershell
python run.py
python run.py --once --dry-run
```

`--dry-run` 会只读打开适配的 WPS 表格、重建时段并记录计划。GUI“消息预览”仅离线解析消息。演练会保存演练去重状态，正式报名使用独立去重标记。

## 常用配置

| 配置 | 说明 |
| --- | --- |
| `runtime.dry_run` | 默认为 true；false 允许填写和同步本人报名日程 |
| `qq.group_names` | 目标可见群名；界面与 QQ 版本差异可能影响读取 |
| `activity.semester_start_date` | 学期第一周周一，YYYY-MM-DD |
| `unavailable.ics_files` | 本机 ICS 路径，GUI 支持导入/移除引用 |
| `tencent_docs.overwrite_incomplete_rows` | 默认 true，允许覆盖残缺个人资料行；完整行始终跳过 |
| `runtime.monitor_documents` | 持续监测尚未报名的场次 |
| `runtime.document_poll_seconds` | 检查后等待，默认 0；页面操作仍会耗时 |
| `runtime.document_open_retries` | 额外重试次数，默认 2，即最多打开 3 次 |
| `runtime.document_deadline_days` | 最后可用未填场次开始前多少天停止报名监测 |
| `runtime.allow_cross_document_conflicts` | 默认允许跨表冲突，并在日程中标红；课程等不可用时间仍排除 |
| `runtime.thread_restart_seconds` | 意外退出且仍待监测的表格线程重启等待，默认 2 秒 |
| `runtime.schedule_sync_seconds` | 已知且结束报名监测的表格只读同步间隔，默认 60 秒 |
| `calendar.start_time` / `end_time` | 日程显示范围，默认 08:00–23:00，仅影响界面 |

报名资料齐全是指已映射的姓名、学院（有该列时）、学号、手机全部非空。开始写入前会重新读取个人字段，覆盖开关可在 GUI 关闭。平台协作编辑仍存在检查与写入之间的竞争窗口。

表格读取限于当前工作表和配置范围；尾部全空行会被裁去。日期/时间不明确的行记录为未解析。复杂分区、横向布局、多工作表等需要进一步适配。

## 日程、记录与恢复

日程表按周显示活动、课程及不可用时间。重叠事项并排，跨表冲突标红，点击色块查看完整时间、地点和双方链接。可修改显示范围、翻周、回到本周和查看已取消事项。

正式监测每轮按学号同步本人报名。结束监测的已知表格由只读线程临时打开、同步后关闭。已确认报名消失时，在完整且可解析的扫描下标为已取消，释放跨表占用并保留取消记录，防止自动重报。删除本地记录而线上仍存在时，下轮会重新导入。

打开失败耗尽重试后跳过并保留原因；可在 GUI 文档记录中允许重试。明确填写失败可能已经写入部分字段，需要查看表格。正常完成、截止、明确填写失败不会被线程重启机制重新报名。单表线程永久阻塞、整个 Python 进程退出目前需要人工处理。

状态与日志存放在 `data/`、`logs/`，包含日程、文档链接和执行记录。`config.yaml`、这两个目录、ICS、浏览器会话和本机环境文件应保留在使用者设备上。仓库的忽略规则覆盖常用运行资料；分享新文件前仍需检查内容。

## 验证状态

项目包含时间解析、去重、表格读写、并发监测、同步及二维码等自动化测试。测试中的姓名、号码、文档链接均为合成占位数据。

```powershell
python -m pytest -q
```

历史复制表单元格写入与刷新持久化有实测记录；真实 QQ → 多份 WPS → 补位 → 日程同步的完整联调，以及长时间零等待稳定性，仍需按 [实测计划](实测计划.md) 验收。测试通过并不涵盖任意表格布局、账号状态和在线多人编辑情况。

QQ 读取依赖当前可见、已加载的消息；最小化、锁屏、版本变化、长消息折叠可能影响结果。登录、验证码、授权和编辑权限变化需要使用者处理。发送 QQ 入群申请后，管理员审核及真正入群需要分别确认。
